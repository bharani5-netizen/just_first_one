# Daylist — Simple To-do App

A small front-end demo with a login screen and a to-do list. It uses plain HTML, CSS, and JavaScript; no packages or server are required.

## Run it in VS Code

1. Open this `simple-todo-app` folder in VS Code.
2. Open `index.html` in a browser. You can also use the **Live Server** VS Code extension and choose **Open with Live Server**.
3. Enter any name and email to open the app.

Add tasks, mark them done, delete them, and use the All / To do / Done filters. Your demo login and tasks are saved in your browser using `localStorage`.

This is a front-end UI demo only. The login does not verify credentials or protect data with a real account.
